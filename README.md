# Matrix Rain

The falling green code effect, full screen in your browser, with a control panel to tune it.

![Matrix Rain screenshot](<Matrix Rain - screenshot.png>)

## Controls

Open the **☰ controls** panel to change:

- Speed, density, font size and glow fade
- Color
- Character set: Matrix kana, binary, Latin and symbols, numbers, or mixed chaos
- Pause, go fullscreen, or hide the panel

## Run it

Download `matrix-rain_1.html` and open it in your web browser. No install, no account, nothing to set up.
